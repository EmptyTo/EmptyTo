Рабочее пространство
Вход с помощью Яндекс ID

Войди через свой Яндекс-аккаунт, чтобы открыть рабочее пространство.

После входа сайт загрузит общую базу из папки приложения на Яндекс Диске и будет автоматически отправлять изменения туда. OAuth-токен используется только в памяти этой вкладки и не записывается в HTML или базу. Не работай одновременно с одной базой на нескольких устройствах: последняя синхронизация может заменить более ранние изменения.
