# Рабочее пространство

Веб-версия сайта публикуется через GitHub Pages из этой папки.

## Авторизация через Яндекс

1. В настройках приложения Яндекс OAuth добавьте Redirect URI:
   https://emptyto.github.io/EmptyTo/yandex-token.html
2. В GitHub откройте Settings → Pages и выберите Source: GitHub Actions.
3. После завершения workflow сайт будет доступен по адресу:
   https://emptyto.github.io/EmptyTo/

Важно: это статический сайт. Яндекс ID используется для входа в текущую вкладку, но база техкарт остаётся в локальном хранилище браузера и не синхронизируется между устройствами. Для полноценной защищённой авторизации и разделения данных разных пользователей нужен сервер.
